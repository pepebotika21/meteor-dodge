# Meteor-dodge
This is my first project in PICO-8; it’s an arcade game where you destroy meteorites by firing from a spaceship.

An initial, playable version is complete, though it doesn’t yet include levels or any advanced features.

I would appreciate any advice or suggestions regarding how it’s built, as well as how it could be improved and brought to completion.
